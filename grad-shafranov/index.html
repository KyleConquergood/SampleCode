Equation and discretisation

The fixed-boundary Grad–Shafranov equation is solved inside the selected Miller-like boundary, with ψ = 0 on the boundary:

Δ*ψ = ∂²ψ/∂R² − (1/R)∂ψ/∂R + ∂²ψ/∂Z² = −μ₀Rjφ.

The nonlinear source is frozen at each Picard iteration:

μ₀Rjφ = C [ fₚ(R/R₀)² + (1−fₚ) ] (ψ/ψaxis)α.

C is recomputed so that ∫jφ dR dZ equals the requested plasma current. The frozen linear system is relaxed with finite-difference SOR, then mixed with the previous Picard iterate. This is a useful conceptual bridge to COMSOL’s coefficient-form or weak-form PDE interfaces.

This is an educational fixed-boundary solver. It does not yet include vacuum coils, a free boundary, an X-point, conducting structures, or force-balance validation against an analytic equilibrium.
